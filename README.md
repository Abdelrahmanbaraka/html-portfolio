# HTML Portfolio Practice

A small beginner project created while learning the fundamentals of HTML. It links simple pages for a movie ranking, a birthday invitation, contact information and an about section.

## What this repository demonstrates

- Basic semantic HTML structure
- Links between multiple pages
- Images and alternative text
- Simple portfolio-style navigation

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/Abdelrahmanbaraka/html-portfolio.git
cd html-portfolio
```

## Project status

This repository is kept as an early learning exercise. It is not my current portfolio and should not be interpreted as a production-ready web project. More representative projects are available on my GitHub profile.
